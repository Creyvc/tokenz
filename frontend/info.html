Info

Tokenz is a token saver for AI prompts. It shortens what you send to a language model while keeping the meaning, so every request uses fewer tokens.

Tokenz started in 2026 as an academic project. Prompts sent to large language models are often longer than they need to be, and every extra token adds cost and waiting time.

Tokenz squeezes a prompt down before it is sent, removing repetition and filler while keeping the parts the model needs to give the same answer. Compare shows the original and the shortened prompt side by side, and Results shows how many tokens were saved.

The project is built for learning and experimenting. It aims to show that smaller prompts can work just as well, and to measure honestly when they don't.
