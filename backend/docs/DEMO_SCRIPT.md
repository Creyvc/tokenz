With `Explain gravity.`, show the honest target-not-reached message. Explain that locks and retained requirements take precedence over a percentage and the existing study covers Conservative only.
3. **TF-IDF (45 seconds):** Choose **TF-IDF**. Click **Try TF-IDF example**, confirm the selected photosynthesis task, leave the budget at 16 and click **Run TF-IDF**. Show the 26-to-13-token result and excluded weather sentence. Select that sentence under **Lock or restore sentences**; show the infeasible-budget message, then use **Use suggested budget** and rerun. Switch back to NLP to demonstrate its independent prompt and result are still there.
4. **Visual comparison (30 seconds):** Copy the TF-IDF example into the NLP screen and run NLP. Return to **Compare methods**: show the Original 26, NLP 26 and TF-IDF 13 bars. Choose **Qwen (optional)** and show “not configured”; its Run button remains disabled. No API request occurs.
5. **Architecture and testing (30 seconds):** Show `architecture.svg`, explain the two-request controller and local checks. Show `TEST_RESULTS.txt`. Mock tests verify revision, timeout, usage aggregation and failures; they are not live Qwen evidence.
